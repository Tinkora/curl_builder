# Support

[简体中文](SUPPORT.zh-CN.md)

## Questions and usage help

Search the [documentation](README.md) and existing
[Discussions](https://github.com/Tinkora/curl_builder/discussions) first. Start a
discussion for usage questions, generated-code review, and ideas that are not yet
actionable bug reports.

## Bug reports

Use the [bug report form](https://github.com/Tinkora/curl_builder/issues/new/choose)
for reproducible behavior that differs from the documented contract. Include the
smallest sanitized request, expected result, actual result, version, browser, and
runtime details. Never include credentials or proprietary payloads.

## Feature requests

Use the feature form and provide evidence from a real workflow, current workaround,
alternatives considered, and a measurable smallest outcome. Feature requests are
not commitments or a roadmap.

## Security

For suspected vulnerabilities, do not open an issue or discussion. Follow
[SECURITY.md](SECURITY.md).

Support is community-based and has no guaranteed response time or service level.

# Changelog

All notable changes to this project are documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions

## [0.1.0-alpha.1] - 2026-08-11

### Added

- A browser-local request builder with English and Simplified Chinese interfaces.
- Code generation for cURL, JavaScript Fetch, Python Requests, Go `net/http`,
  Rust Reqwest, and Node.js `http`/`https`.
- A non-executing cURL subset parser with explicit shell and file-read rejection.
- Stable validation and WASM error codes, input limits, content-type checks, and
  generated syntax tests.
- Responsive, keyboard-accessible browser tests at four target widths.
- Pinned CI, dependency auditing, CodeQL, Pages, release evidence, checksums,
  SBOM generation, and build attestations.
